Propósito: Validación de la infraestructura de descarga del sitio web corporativo

INSTRUCCIONES PARA DESPLIEGUE DE ARCHIVOS REALES:
-------------------------------------------------
1. Para distribuir un archivo APK real, copie el archivo compilado en esta carpeta:
   public/downloads/novamobile-release.apk

2. Actualice el archivo de configuración:
   src/config/downloads.js

   Modifique el objeto del producto correspondiente:
   {
     id: 'novamobile-apk',
     fileName: 'novamobile-release.apk',
     fileSize: '18.4 MB',
     version: '1.0.0',
     isAvailable: true,
     ...
   }

3. Al reconstruir o desplegar en el contenedor Docker Nginx, el archivo estará
   disponible inmediatamente para descarga directa a través de:
   /downloads/novamobile-release.apk
